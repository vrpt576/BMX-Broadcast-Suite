# Apply BMX Broadcast Suite v1.2.8

This is an overwrite package for a working v1.2.7 event-selection branch.

1. Stop the manually running BBS/uvicorn process.
2. Make a branch or backup of the repository.
3. Extract the ZIP into the repository root and allow files to be replaced.
4. Do not replace or commit `.env`, `data/`, logs, or `.venv/`.
5. Normalize remaining installer/tray/documentation version references from the existing release:

```powershell
.\scripts\prepare-v1.2.8-release.ps1
```

6. Run:

```powershell
cd C:\Users\user\Documents\BMX-Broadcast-Suite
.\.venv\Scripts\python.exe -m compileall -q connector database tests
.\.venv\Scripts\python.exe -m pytest -q
```

7. Start BBS and validate:

```powershell
.\.venv\Scripts\python.exe -m uvicorn connector.main:app --host 0.0.0.0 --port 8000
```

Useful checks:

```powershell
Invoke-RestMethod http://127.0.0.1:8000/api/current/program | ConvertTo-Json -Depth 8
Invoke-RestMethod 'http://127.0.0.1:8000/api/motos?all_rounds=true' | ConvertTo-Json -Depth 5
Invoke-RestMethod http://127.0.0.1:8000/api/lineup/current | ConvertTo-Json -Depth 8
Invoke-RestMethod http://127.0.0.1:8000/api/results/current | ConvertTo-Json -Depth 8
```

8. Review and commit:

```powershell
git status
git diff --stat
git add connector database tests scripts README.md ROADMAP.md CHANGELOG.md docs V1.2.8-APPLY.md
git commit -m "Release v1.2.8 with round-aware RaceManager stages"
git push -u origin HEAD
```

The ZIP intentionally contains no credentials, runtime state, logs, virtual environment, or RaceManager data exports.
