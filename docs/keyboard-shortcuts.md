# Race Director Keyboard Shortcuts

- **Space** or **Right Arrow**: next moto
- **Backspace** or **Left Arrow**: previous moto; backward movement requires confirmation
- **[** / **]**: previous or next race phase
- **M**: current-moto graphic
- **L**: rider-lineup graphic
- **R**: results graphic
- **H**: hide all BBS graphics

Shortcuts act only while the Race Director page has focus. Avoid typing into form fields while using shortcuts. Confirm the on-air graphic and moto status tiles after every action.

Round 1 Break and Main Break intentionally use Director buttons only. No break
keyboard shortcut is assigned, avoiding conflicts with the established live
controls.
