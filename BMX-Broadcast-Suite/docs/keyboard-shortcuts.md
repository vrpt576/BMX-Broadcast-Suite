# Race Director Keyboard Shortcuts

- **Right Arrow**: next moto
- **Left Arrow**: previous moto; backward movement requires confirmation
- **Up Arrow**: next race phase
- **Down Arrow**: previous race phase
- **C**: current-moto graphic
- **L**: rider-lineup graphic
- **R**: results graphic

Shortcuts act only while the Race Director page has focus. Avoid typing into form fields while using shortcuts. Confirm the on-air graphic and moto status tiles after every action.
